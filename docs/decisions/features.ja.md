# 機能の決定

> For the English version, see [features.md](features.md).

サイトが何をどう提供するかについて閉じた判断と、その理由、却下した案、決定を開け直す条件を持つ。今の挙動は [AGENTS.md](../../AGENTS.md) の「Site architecture」にある。

## 発音の再生には Web Speech API を使う

- **決定** (2026-05-16、コミット `2fc3eb5`): 種ページの各オノマトペのセルに再生ボタンを置き、ブラウザに組み込まれた音声合成 (`speechSynthesis`) で読み上げる。どう読むかは、OS とブラウザの音声エンジンに任せる。
- **理由**: 狙いは、訪問者が自分の言語以外のオノマトペの発音を耳で確かめられること。Web Speech API は、外部への依存も追加の費用もファイルも無しでそれができ、4 言語 (`ja-JP` / `en-US` / `ko-KR` / `zh-CN`) に一度に対応する。外部への依存を持たないというサイトの方針にも合う。
- **却下した案**:
  - クラウドの音声合成サービスで mp3 を先に作ってコミットする。305 種 × 4 言語でおよそ 1,200 ファイルになり、作る費用・リポジトリの大きさ・API キーの管理が、得られるものに見合わなかった。完全な静的サイトのままにはできた。
  - 文字の横に IPA の表記を並べる。「どう発音するか」には、表記より音のほうが直接答える。
- **開け直す条件**: 発音の質に強い不満が出たとき。そのときは、先に作った音声の案へ移る。そのために、ビルドは `data/animal-sounds-data.xlsx` を読んだ直後に生成の手順を足せる構造を保つ。

## 5 つ目の表示言語は足さない

- **決定** (2026-10-17): 5 つ目の表示言語は足さない。表示言語は ja / en / ko / zh のままにする。
- **経緯**: `CLAUDE.md` に「今後の拡張候補」の節があり、行を足すだけで言語を足せると書いていた。コードは 4 言語を直接書いていて、その記述と合わなかったので、節を消した ([#45](https://github.com/semnil/koe-zukan/pull/45))。
